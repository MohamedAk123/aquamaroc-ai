# DEMO — Données entièrement synthétiques

`reservoirs_demo.xlsx` contient quatre mesures inventées pour les tests de l'import.
Les noms, dates et valeurs ne représentent aucun barrage réel. Les coordonnées et
capacités restent absentes. Le générateur est `python -m pipelines.ingestion.demo`.
La première ligne du classeur porte la bannière DEMO et la deuxième les en-têtes.
Ce jeu ne permet aucune validation d'un modèle prédictif.
