# Plan de correction AquaMaroc AI

Ce plan découle de l’[audit technique](AUDIT_COMPLET_AQUAMAROC.md). Il n’engage aucune mise en œuvre avant autorisation. Le périmètre de livraison peut être celui d’un observatoire de lecture des relevés officiels du Tensift avec analyse rétrospective. Les prévisions demandent une décision d’éligibilité distincte pour chaque horizon.

## Ordre de décision

1. Confirmer la cible de livraison et appliquer les points 1 à 5 pour l’observatoire officiel.
2. Vérifier la recette de bout en bout à partir du commit candidat en environnement cible.
3. Réévaluer les horizons quand les nouvelles archives sont disponibles. Autoriser les expériences uniquement sur les horizons éligibles et publier une prévision seulement après réussite sur un test final indépendant.
